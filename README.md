# Diseño de una herramienta digital para la organización de tutorías y el seguimiento académico de los estudiantes de la modalidad en línea de la Universidad Agraria del Ecuador[cite: 1]

##  Descripción del Proyecto
Este repositorio contiene el prototipo y la documentación conceptual de un sistema web enfocado en la gestión de tutorías y el acompañamiento académico estudiantil. El sistema delimita el alcance funcional para tres actores principales: Estudiante, Docente Tutor y Administrador, facilitando la comunicación técnica y respondiendo a las necesidades del acompañamiento educativo en la modalidad en línea[cite: 1].

##  Objetivo General
Diseñar una propuesta de sistema web para la gestión de tutorías y seguimiento del progreso de los estudiantes, mediante el análisis de necesidades y la aplicación de herramientas de ingeniería de software, con el fin de mejorar la organización y el control de la información.

##  Cuatro Funcionalidades Principales
1. **Inicio de sesión y gestión de accesos:** Autenticación institucional e inicio de sesión basado en roles específicos (Estudiante, Tutor, Administrador)[cite: 1].
2. **Programación de tutorías:** Agendamiento directo de citas por parte de los estudiantes según la disponibilidad de bloques horarios y asignación de tutores[cite: 1].
3. **Registro de sesiones de tutoría:** Registro estructurado de bitácoras y actas digitales de acompañamiento por parte del tutor[cite: 1].
4. **Consulta del progreso académico:** Panel visual centralizado para consultar el historial de evolución académica y visualizar las recomendaciones pedagógicas[cite: 1].

##  Herramientas Utilizadas
* **GitHub:** Control de versiones, gestión del código fuente y mantenimiento del expediente del proyecto.
