# Sistema de Gestion de Tutorias
Prototipo y documentación conceptual de un sistema web integral orientado a la gestión de tutorías y el acompañamiento académico estudiantil en la Universidad Agraria del Ecuador. Incluye el modelado de requerimientos, diagramación UML, diseño de prototipos visuales y control de versionamiento para tres roles clave: Estudiante, Docente Tutor y Administrador.
Objetivo General
Diseñar una propuesta de sistema web para la gestión de tutorías y seguimiento del progreso de los estudiantes, mediante el análisis de necesidades y la aplicación de herramientas de ingeniería de software, con el fin de mejorar la organización y el control de la información
Integrantes del equipo:Abarca Orrala Pedro Segundo,Delacruz Castillo Henry Alexander,Lopez Mendoza Genessis Milena
Cuatro funcionalidades principales
Iniciar sesión: Permite a los usuarios acceder al sistema mediante sus credenciales institucionales. 
Agendar tutoría: Permite al estudiante programar una sesión de tutoría con su tutor asignado. 
Registrar sesión de tutoría: Permite al docente tutor registrar la información de cada sesión realizada. 
Consultar progreso académico: Permite al estudiante visualizar su historial y seguimiento académico. 
Herramientas utilizadas
StarUML,Trello,Figma,Google Docs
