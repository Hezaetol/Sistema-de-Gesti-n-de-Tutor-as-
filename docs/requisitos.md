# Requisitos del Sistema de Gestión de Tutorías

## Requisitos Funcionales (RF)
1. **RF-01 (Autenticación por roles):** El sistema debe permitir el inicio de sesión seguro para usuarios con roles de Estudiante, Docente Tutor y Administrador.
2. **RF-02 (Agendamiento de tutorías):** El sistema debe permitir a los estudiantes agendar citas de tutoría seleccionando bloques horarios disponibles.
3. **RF-03 (Registro de bitácora y seguimiento):** El sistema debe permitir al Docente Tutor registrar actas digitales y bitácoras con el progreso académico del estudiante.

## Requisitos No Funcionales (RNF)
1. **RNF-01 (Seguridad):** La autenticación de usuarios y la transmisión de datos deben realizarse mediante protocolos cifrados HTTPS.
2. **RNF-02 (Diseño adaptativo):** La interfaz web debe ser responsiva y accesible desde dispositivos móviles y de escritorio.
